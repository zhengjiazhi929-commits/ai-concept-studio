# Agentic Coding 本地演示项目

这是黄金样例视频使用的本地 SaaS 演示环境，所有客户、公司、电话和邮箱均为虚构数据。

它用于真实记录以下过程：

1. Agent 读取任务和项目；
2. 运行验收测试并看到失败；
3. 修改权限、脱敏和异步导出逻辑；
4. 重新运行测试；
5. 在浏览器中验证结果；
6. 查看 Diff 和交付证据。

## 重要说明

- `baseline` 标签固定了故意不合格的初始实现，用于复现 Agent 开始工作前的真实失败；
- `first-pass` 与 `fixed` 标签指向 Coding Agent 的第一版实现；该版本一次通过全部 5 项验收测试，没有人为制造额外失败；
- `main` 分支保存当前完成态：管理员异步导出、普通用户拒绝、CSV 脱敏和浏览器状态轮询；
- 不得把本项目用于生产环境；
- 不含真实账号、密钥、客户数据或第三方服务；
- 视频中必须标注“本地演示环境 / 虚构数据”。

## 运行

使用项目配置的 Node.js：

```text
npm test
npm start
```

默认访问：`http://127.0.0.1:4173`

正式录制前，以 `TASK.md` 为任务合同，以 `tests/export.test.mjs` 为可执行验收条件。

## 可复现检查点

```text
baseline   d3ef196  5 项测试：1 通过、4 失败
fixed      c619b0c  5 项测试：5 通过、0 失败
```

最终 HTTP 验收还会检查：页面 `200`、普通用户 `403`、管理员创建任务 `202`、任务进入 `complete`、下载 `200`、敏感字段已脱敏。

已知限制：任务和 CSV 只保存在当前进程内存中；角色查询参数只是本地演示机制；真正的大规模生产导出应使用持久化队列、正式鉴权和独立工作进程。
