## 从讲稿到画面的制作逻辑

每组先写以下六项，再安排布局，不能先摆一排卡片再往里填文字：

1. **解释目标**：这段看完之后，观众应能说明什么？
2. **必要对象**：哪些东西必须看见？对象形状应表示实际身份。
3. **关键变化**：筛选、复制、查找、返回、分派等动词具体作用于谁？
4. **开始状态**：尚未发生什么？需要保留哪些来源和候选？
5. **结果证据**：内容真的进了窗口、返回值真的对应记录、任务真的只交给一路。
6. **观看顺序**：每个关键状态有明确焦点；不同阶段保持对象身份与空间关系。

复用画风、对象能力和动作规则，不固定每期的画面构图。信息卡片负责归纳，独立插画负责解释过程。
这不是任意讲稿自动生成分镜的编排器；新主题仍需要内容判断、分镜设计和实际样例确认。
