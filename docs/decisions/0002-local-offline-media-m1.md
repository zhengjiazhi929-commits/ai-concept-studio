# ADR-0002：M1 旁白与渲染采用本地离线路径

状态：Accepted
日期：2026-08-25

## 背景

M1 的目标是验证工作流、媒体和人审闭环，不需要为此产生 Provider 费用。用户明确要求旁白
和渲染只用本地能力，并在两道媒体 Gate 停止等待人工批准。

## 决定

- 旁白候选使用已缓存且哈希固定的本地 Kokoro 模型/音色，并校验固定 Python 解释器和
  依赖清单；生成子进程在导入推理栈前拒绝 Python socket API，同时设置离线环境变量。
- Remotion 使用本地代码、tracked 图片和本地 Chromium，禁止远程媒体 URL。
- 候选先写 `outputs/` manifest，不自动登记、不自动批准；人工选择后通过安全上传/登记路径进入 Episode。
- 素材/声音 Gate 通过后才渲染；QA 通过后再进入最终成片 Gate。
- 项目生成路径配置并执行的外部/付费生成调用、模型下载、文本上传和自动发布均为 0。

## 结果与限制

可用低成本方式证明 M1，但本地 TTS 音质和当前 540×960/15 fps 规格只是验收样片标准，
不代表正式发行品质。Python socket API 拒绝不是 OS 级网络沙箱或全机流量取证。当前音色
包许可证未独立核实，因此候选仅限本地内部评审，不具备公开或商业发布资格。更换音色、
模型、运行时或渲染规格会改变哈希并触发重新审核。

## 回退

候选不写 Episode，可直接舍弃。已登记新旁白会失效 render/QA/final，但保留历史版本；
渲染失败删除临时文件，不覆盖旧成片。
