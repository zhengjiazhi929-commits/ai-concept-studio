## 可复用表达规则

- 先确定观看后能理解的关系，再选择对象与动作。移动必须回答“什么从哪里到哪里”，展开必须回答“新增看到了什么”。
- 一个动作推进一个解释。先匹配，再展开；内容完全到达后才显示载入状态。不能用与事实不同步的成功标记。
- 索引与完整内容是不同的展示层级。目录保留名称和描述；命中项的副本才展开执行步骤与验收标准。
- 每个阶段保留原件身份，不能让复制动作被误读为删除或搬走原件；未命中项不进入上下文。
- 图形用来承担独立语义和动作，不给每段卡片文字自动配图标。内容卡片保持纯文字；纸页轮廓表示文档，上下文轮廓表示接收边界。
- 同类对象保持同样的形状、描边、字体和比例。浅色薄荷背景及颜色复用现有 tokens；保留完整 3px 边框，不用淡化边框表达未选中。
- 画面重排不整体缩字。主对象标签固定 44px，辅助文字 28px；空间不足时收起次要说明，不能将正文挤出轮廓。
- 展开先提供空间，再显示完整文字；不露出被截断的半行字。轨迹采用水平/垂直分段，并检查中途是否遮住无关对象。
- 字幕/解释句不加底框；标题从首帧清楚可见。只有视觉语义需要时才加入箭头，不能堆叠线路。
- 右上角沿用 approved-v013 连续动态 Logo；这是水印的既有身份，不是本样片已通过验收。
- 控制在一次短演示内验证理解，不为了时长填充空转、漂浮或重复镜头。所有动作由帧确定，禁止随机数、墙钟动画和 CSS transition。
