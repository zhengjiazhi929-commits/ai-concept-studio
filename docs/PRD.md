# AI Concept Studio 产品需求（M1）

版本：2026-08-25

状态：M1 本地闭环执行中

## 用户与问题

首位用户是 Zhengjiazhi，一名需要理解并解释 AI 技术概念的产品经理。当前痛点不是缺少
一次性的 AI 文案，而是缺少一条可追溯、可恢复、不会绕过人工判断的视频生产链。

产品需要把固定、合法的概念输入转成研究证据、脚本、分镜、素材、旁白、视频和 QA，
并让每个关键决定都绑定精确版本，而不是让 Agent 自己宣布“完成”。

## M1 目标

使用 golden-001 固定输入，在本机生成一条 36 秒竖屏技术样片，证明：

1. 输入、事实、脚本、分镜、素材、旁白、成片和 QA 可以追溯。
2. 失败后可以停止、定位、恢复或回退，不重复未知费用。
3. 研究、脚本、分镜、素材/声音和最终成片五道 Gate 都由人决定。
4. 旁白和渲染不调用付费或外部生成 API。
5. 通过测试、机器审核、业务验收和发布状态分别报告。

36 秒样片是最小技术闭环，不代表产品最终的 8～12 分钟内容规格或发行品质。

## 用户可见流程

固定概念输入 → 研究与来源 → 人工研究 Gate → 脚本 → 人工脚本 Gate → 分镜 →
人工分镜 Gate → 素材与本地旁白 → 人工素材/声音 Gate → 本地 Remotion 成片 →
技术与画面 QA → 人工最终成片 Gate → 本地交付。

最终 Gate 不自动授权公开发布，合并 main 也属于另一个决定。

## 功能要求

- Episode 是单期状态真源，所有下游状态由当前版本和哈希决定。
- Workflow Kernel 决定合法动作、权限、预算、并发、恢复和 Gate 有效性。
- Worker 只能使用允许的工具和一次性 Capability，不能扩权或批准 Gate。
- 外部内容经过 Schema、URL、DNS/IP、大小和来源校验，只能作为不可信数据。
- Provider 结果不明时冻结预算和重试，只有鉴权人工裁决可解除。
- 素材、旁白和成片使用版本化文件、真实 bytes、SHA-256 和 CAS。
- Prompt、模型、路由、Rubric、实现和评测输入变化会使旧证据失效。
- 所有媒体均可试听或播放，并有机器报告与人工决定入口。

## 非功能要求

- 精确 Node / pnpm、frozen lockfile、离线 Fixture、CI、依赖高危门禁。
- 默认 shadow 和 fixed fallback；assisted / active 在可信准入完成前硬锁。
- 日志与错误字段级脱敏；秘密、live 数据、模型权重和大型媒体不进入 Git。
- 同一输入可重复运行；失败不覆盖已批准版本；回滚有可执行演练。

## M1 验收

- 540×960、15 fps、36 秒 H.264/yuv420p MP4，包含可解码本地旁白音轨。
- 四项登记素材和旁白在批准时、渲染前、QA 时均通过真实字节校验。
- 六段旁白与 0–36 秒时间轴绑定；项目生成路径配置并执行的外部/付费生成调用为 0。
- 本地旁白 manifest 必须明确：Python socket API 应用层拒绝不等于操作系统级断网或
  全机流量取证；未独立核实音色包许可证的候选只能用于本地内部评审。
- 机器技术检查、抽帧检查和一次不中断的 1× 人工观看均有结论。
- 素材/声音 Gate 与最终成片 Gate 都绑定当前版本、哈希和机器报告。
- 全量测试、隔离复现、依赖门禁和回滚演练通过。
