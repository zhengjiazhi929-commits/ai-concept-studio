# 黄金样例执行流程 v0.1

黄金样例采用“人工编排、AI 协作、人类审批”。它不是要求创作者独自手工完成，也不是让尚未开发的系统自动运行。

本文件描述通用目标流程。当前 36 秒 M1 不运行候选抓取，不调用外部或付费生成 API；只使用
仓库内固定输入，并在上游三道 Gate 通过后使用本地 Kokoro 与本地 Remotion。任何 Gate 都
必须停下来等待 Zhengjiazhi 决定。

## 1. 角色分工

Codex 负责：

- 搜集候选选题与一手来源；
- 生成选题卡；
- 整理证据包和事实主张；
- 分析技术机制与产品影响；
- 生成并修改大纲、脚本和分镜；
- 辅助创建图表、素材、配音和初版成片；
- 记录过程、版本、耗时和返工原因。

创作者负责：

- 选择选题与角度；
- 批准研究证据与关键事实；
- 加入个人观点与表达偏好；
- 审批脚本；
- 审批分镜；
- 审批素材与声音；
- 验收成片并决定是否发布。


正式选题前只创建候选卡，不提前填充黄金样例目录。

对当前 36 秒 M1，`07-script.md` 和 `08-storyboard.md` 是早期长版内容的参考来源，不是
当前 Gate 产物。当前 Gate 2 绑定 Episode 中六段结构化短脚本；Gate 3 绑定 Episode 中
六镜、字幕、渲染规格和逻辑证据引用。参考文件路径本身不能构成批准证据。

## 3. 执行步骤与审批点

### 步骤 A：候选发现

输入：

- 最近 30～45 天一手发布；
- GitHub、Hugging Face、论文等采用信号；
- 博主人工观察卡；
- 账号定位与选题规则。

输出：

- 5 张候选选题卡；
- 每张卡的评分、来源、风险和推荐角度。

人工输入：创作者选择一个选题，或要求换角度。选题是生产输入，不计入
Workflow Kernel 的五道人审 Gate。

### 步骤 B：研究与证据

输出：

- 来源登记表；
- 事实主张台账；
- 技术机制简报；
- 产品影响简报；
- 不确定信息列表。

Gate 1（研究）：创作者批准当前版本的研究证据、关键结论和个人判断。

### 步骤 C：大纲与脚本

输出：

- 章节大纲；
- 第一版脚本；
- 技术审稿意见；
- 产品视角审稿意见；
- 修改后的定稿候选；
- 事实与脚本映射。

Gate 2（脚本）：创作者批准当前版本的表达与观点定稿。

### 步骤 D：分镜

输出：

- 时间轴分镜；
- 架构图和信息图清单；
- 录屏清单；

Gate 3（分镜）：创作者批准当前版本的时间轴、画面结构和证据对应关系。
批准必须同时绑定当前版本、结构化内容 SHA-256 和机器审核报告；历史记录的哈希若与当前
内容不一致，系统必须回到本 Gate，不能把“曾经 approved”沿用到新内容。

### 步骤 E：素材与声音

输出：

- AI 素材提示词；
- 素材来源、版权与本地/外部制作方式；
- 配音、字幕和音乐配置及可试听候选；
- 素材与声音的机器检查结果。

Gate 4（素材/声音）：创作者批准当前素材包和声音版本。未批准前不得进入正式渲染。

### 步骤 F：渲染与成片验收

输出：

- 初版视频。
- 媒体技术检查和视觉 QA 报告。

Gate 5（最终成片）：创作者只验收当前版本成片。系统和 Agent 不得代替人工批准，也不得把
“测试通过”推导为业务验收。公开发布是 Gate 5 之后的独立明确决定，还要单独确认许可证、
平台、标题、账号与发布范围；最终 Gate 本身不自动授权公开发布。

### 步骤 G：复盘

记录：

- 每一步耗时；
- 人工修改的类型和原因；
- 模型最容易出错的部分；
- 重复劳动；
- 适合最先自动化的环节；
- 发布后的内容表现。

## 4. 内部 M1 完成标准

- 达到 `docs/02-quality-rubric.md` 的内部质量线，但不据此自动取得公开发布资格；
- 所有关键事实可追溯；
- 研究、脚本、分镜、素材/声音、最终成片五道 Gate 均有版本、哈希、机器审核与
  人工决定记录；
- 从选题到成片的全部产物齐全；
- 能明确列出下一阶段最值得自动化的 3～5 个步骤；
- 后续 Agent 可以使用该样例作为固定回归测试。

当前 Kokoro 音色许可证尚未独立核实，即使内部 M1 完成，也只能用于本地内部评审。

## 5. 公开发布的额外条件

- 最终成片 Gate 已批准，且批准仍绑定当前 MP4、QA 报告和哈希；
- 音色、字体、素材、音乐和第三方内容许可证均有可审计记录；
- 标题、平台、账号、受众范围和发布时间得到独立人工确认；
- 合并、push、部署和发布各自获得明确授权，系统不自动执行。
