# 许可证与媒体来源台账

更新时间：2026-08-25

## 当前结论

仓库根目录目前没有项目级 `LICENSE`，因此还不具备“可开源发布”的最低许可证条件。
这不阻断本地 M1，但阻断 GitHub v0.1.0 发布。许可证选择必须由 Zhengjiazhi 决定，Agent
不能替项目负责人授权代码或第三方内容。

当前固定 Kokoro 音色包只有文件哈希，许可证尚未独立核实。因此即使本地技术链生成了
WAV/MP4，也只能用于 Zhengjiazhi 的本地内部评审；在补齐音色授权和项目级 LICENSE 前，
不得把候选或成片描述为可公开、可商用或可再分发。

| 内容 | 来源 / 位置 | 当前使用边界 | 发布前动作 |
|---|---|---|---|
| 项目源码 | 本仓库 | 私有本地开发 | 选择并加入项目 LICENSE |
| amicro motion 素材 | `studio/src/video/motion-library/upstream/amicro/` | 按随附 LICENSE/NOTICE/THIRD_PARTY | 保留声明，逐项核对衍生产物 |
| 黄金样例产品截图 | 本地虚构 SaaS demo，`episodes/golden-001/production/captures/` | 自制、虚构数据，用于证据画面 | 保留生成/捕获说明与哈希 |
| 文档参考图/GIF | `docs/assets/` | 仓库内设计与审查资料 | 补齐逐项作者/来源；不明项不随公开版发布 |
| Phosphor Icons | npm 依赖 | 应用 UI | 随依赖许可证清单保留声明 |
| React / Remotion / Undici 等 | `studio/pnpm-lock.yaml` | 构建和运行 | CI 生成依赖许可证清单并复核不兼容条款 |

| macOS 系统语音 | 操作系统提供 | 只允许本机试听/候选，音频不默认入 Git | 遵守 Apple 条款，不把系统组件再分发 |
| 外部网页/论文文字 | URL 与短引用 | 事实核验和必要短引用 | 不复制长文；保留作者、URL、时间和引用范围 |
| 背景音乐/音效 | 当前 M1 无 | 默认不使用 | 新增前登记来源、许可证、署名与商业使用范围 |

## 素材登记最小字段

`asset_id`、本地相对路径、bytes、SHA-256、作者/来源、source URL（如适用）、获得时间、
许可证、允许用途、署名要求、隐私/肖像状态和验证人。缺任一关键授权字段时，不进入成片。

## 禁止事项

- 不克隆、冒充或暗示真实人物为本项目配音。
- 不把搜索结果图片或竞品视频直接当可用素材。
- 不把“公开可访问”理解为“可复制或可商用”。
- 不提交模型权重、系统字体、付费素材、Cookie、账号数据或未授权成片。
