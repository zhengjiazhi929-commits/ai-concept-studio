## 可复用执行合同

- `illustration`：独立插画槽与文字槽分开，使用封闭语义词汇及枚举状态，不接受任意 SVG。处理器、闸口、档案、数量组、交付箱、交期、模块、轨迹和刻度可复用；图形状态必须由对应口播 cue 驱动。
- `present`：同一对象更新屏显、插画状态或显式布局，不能写入业务信息值、核验结果或物理材料副本。真实复制源不得用屏显更新伪造数据变化。
- `connect`：只接受正交关系线，支持限定回路；端点必须可见，箭头在连线绘制完成后出现。不能用关系线代替材料送入动作。
- `regionId`：表达真实空间包含，检查祖先、循环、可见性与边界；不等同于纸页 `containerId`。底层范围先画、线居中、主体和托盘前沿后画。
- `copy → transfer → arrive`：保留源物件身份，副本进入实际窗口/托盘后形成可检查的容器成员；到达不代表审批、核验、业务执行成功。
- `reposition`：只允许受限根纸页/标签横向或纵向位移；检查完整扫过区和并发动作，不生成外部业务状态。
- `tracks`：无字无箭头的正交路径，可按 cue 改路径、画线或高亮；空路径显式退场。不能拿无向轨道暗示因果、测量值或成功结果。
- `chapterPlan`：2–6 章完整有序覆盖镜头，章节名按大纲 cue 揭示；名称以等宽单行目录排布，进度轨长度仍按编译后的实际场长比例分配，不能为了短章文字而改成等时长。正式分镜必须自带相同绑定，不能靠顶层字段注入导航；无正式稿的离线编译才允许顶层计划。
- 当前模型检查覆盖事件起止、边界、中点及轨道变化；额外逐传送帧审阅另留证据。抽样几何通过不代表未采样帧、像素或连续观看已通过。

## 验证与执行入口

```sh
node --test tests/editorial-diagram*.test.mjs tests/editorial-tracks-and-reposition.test.mjs \
  tests/editorial-chapters.test.mjs tests/editorial-business-figures.test.mjs tests/timed-editorial-diagram.test.mjs
pnpm ci:editorial-diagram-smoke
pnpm verify
```

浏览器 smoke 使用合成内容和隔离目录，覆盖实际像素中的插画轮廓、关系线、原件/副本、托盘遮挡、非等分导航与全局帧 logo；不能拿它代替本期验片。

正式机器复核使用 [本地确定性分镜审核](25-local-storyboard-review.md)。预览与提交分别执行；内容、上游、配置或实现变化后必须重新预览，不得重放旧快照。代码测试、正式报告、用户视觉验收和发布分别记录。
