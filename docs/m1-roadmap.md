# M1 最小视频闭环路线图

更新时间：2026-08-25
目标 Episode：`golden-001`

## M1 的业务定义

同一份固定且合法输入，在固定本地运行环境中可以重复地产生：研究与脚本来源、真实素材、
可试听旁白、可播放 MP4、机器 QA 和五道人审决定。上游是 Research / Script / Storyboard
三道 Gate，媒体阶段另有 Assets/Voice 与 Final 两道 Gate；任何一步失败都能定位、恢复且
不会覆盖已批准版本。

## 量化验收

- 540×960、15 fps、36 秒、H.264、yuv420p，存在可解码音轨。
- 旁白覆盖 0–36 秒，六段与当前字幕逐字绑定，时长误差不超过 0.01 秒。
- 四张 evidence 素材文件存在，登记 bytes/SHA-256 与审批时重读字节一致。
- MP4 大于 50 KB，登记 bytes/SHA-256 与 QA 时重读一致。
- 抽取每个场景中点、所有转场窗口和周期帧；无黑帧、截断、安全区冲突或明显空画面。
- 进行一次不中断的 1× 人工观看；自动抽帧不能替代这一步。
- 项目生成路径配置并执行的外部/付费生成调用数为 0；manifest 明确记录应用层网络
  拒绝范围和“不具备 OS 级流量取证”的证据边界。
- Research、Script、Storyboard、素材/声音、最终成片五道 Gate 均由已认证操作员完成，
  Agent 不代签；媒体阶段的两次决定不能替代上游三道决定。

## 失败和回退

- 旁白不满意：保留候选，生成 `vNNN+1`，不登记旧候选。
- 素材/声音驳回：保存反馈，失效 render/QA/final，回到 Assets 或 Voice。
- 渲染失败：删除 `.rendering`，保留旧 MP4 和获批上游版本。
- QA 失败：保留报告，创建新成片版本；不修改已生成文件。
- 成片缺失/哈希漂移：自动使 QA/终审 stale，恢复可信备份或重新渲染。
- 代码回退：回退任务提交；运行状态按备份和版本化 manifest 恢复，不 reset 用户工作。
