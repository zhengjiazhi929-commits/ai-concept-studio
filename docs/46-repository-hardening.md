# 仓库安全、可复现性与文字排版加固

日期：2026-10-14。范围由 Zhengjiazhi 选择：修复审查中已确认的八项问题、修复本地验证环境；随后明确同意将依赖安全补丁纳入本轮。不是新视频制作或 Git 发布。

## 验收与保护边界

- 不修改现有 MP4、配音、字幕、讲稿、正式 Episode 或五道人审 Gate。合成 Fixture 和静态浏览器测试不能代替用户视觉接受。
- 以开始前 1,164 项源码/非忽略文件 SHA 为基线，在隔离 clone 实施。同步时只复制本轮差异，目标偏离基线即停止；不 reset/stash/clean，不夹带历史 dirty 作为本轮成果。
- 不 commit/push/merge，不调用生成模型或付费 API，不进行整片重渲染。测试可使用临时数据、真实本地字体、合成静帧和自有子进程。
- R3 安全边界按失败用例先 RED、最小修复后 GREEN，再全量验证。与最新源码不匹配的旧通过记录不作为本轮证据。

## 本轮实现

| 编号 | 原问题 | 修复及失败行为 |
| --- | --- | --- |
| A1 | 私有 GET/媒体缺少 Host 边界 | 所有请求先校验精确本地主机名、实际绑定端口与 Origin；拒绝外来 Host/跨站来源，保留写操作会话与 CSRF 校验。不是对本机恶意进程的隔离。 |
| A2 | 导入/完成/准备过程中授权过期仍能提交 | 五项服务在每次持久化、manifest、CAS、审计前复核原授权。CAS 后失效如实返回已提交但审计待修复；新授权补审计不重复提交。包括 null/undefined 审计异常回归。 |
| A3 | 缓存正式候选可能已经过期 | 在趋势存储锁内按当前时间和原始来源重新计算资格，绑定选择证据；过期或输入变更要求刷新，不能静默沿用旧标签。人工选题与五个 Gate 语义不变。 |
| A4 | URL.pathname 导致中文/空格路径失败 | 使用 fileURLToPath，并增加真实中文空格临时目录回归。 |
| A5 | 动画阶段错误依赖分句 ID 的数字后缀 | 按已校验分句列表顺序定位阶段；合法重命名不改变动画，未知分句拒绝。 |
| A6 | 卡片大小与真实文案不匹配 | 保留短文案原几何与字号；长文案先扩宽/增高/正交重排，不能放下则明确拆场景。sources 保持单列并更新连接；真实字体加载后再做 DOM 包含与文字重叠检查。 |
| A7 | 哈希仅绑定锁声明而非实际执行依赖 | 绑定包字节、未声明但可加载的安装包、松散模块文件和符号链接目标；文件、目录成员及链接末尾重验。每个新片段发布续跑 checkpoint 前仍做完整校验。 |
| A8 | Chrome 在启动握手失败时可能泄漏 | 通过 Node 24 子进程诊断事件及异步作用域记录本次子进程；失败仅停止本次拥有的进程和经验证的私有临时 profile，不扫描或清理用户 Chrome。 |

文字防溢出不是任意文本自动排版承诺：极端长文案会主动拒绝渲染并要求拆场景。新增 DOM 检查只覆盖 `data-full-card` 标注的通用卡片，不包括复用旧组件的十个语义场景、所有图形/字形墨迹或卡片外的标题字幕。语义插画仍有具体内容映射，本轮没有把整个系统改造成通用动画引擎，也不能宣称全片视觉自动合格。

依赖身份检查针对持久漂移，不是恶意“改动后立即恢复”的操作系统沙箱；完整检查有 I/O 成本。只删除片段开始的重复扫描，不能删除新 checkpoint 发布前的验证。外部符号链接无法纳入安装根时直接拒绝，不用未验证的包继续生产。

A2 在 CAS 前过期时，已写出的不可变产物可能保留为未登记文件；新授权重试须重新核验后接管，不自动登记。A8 启动失败回归使用锁定 Remotion 的 VM 及真实 owned Node 子进程，不是实际 Chrome 握手超时实测；停止子进程失败时保留 profile，避免误删仍使用中的目录。

## 运行环境与长期回归

- Node 24.19.0、pnpm 11.19.0、Remotion 4.0.504 保持锁定；Mac 启动器优先使用经版本校验的用户缓存 pnpm，不自动升级。
- Python QA 保持 CPython 3.12.13、NumPy 2.3.5、Pillow 12.3.0；按现有带哈希 requirements 安装。旧 QA 解析器会 realpath 解释器，因此本地专用 venv 必须使用 `--copies`，不能让链接返回无依赖的 base 环境。
- `pnpm verify` 新增 `ci:full-card-text-smoke`：生产卡片组件 + 本地 Noto 字体 + 固定合成文案，检查短卡基线不漂移、长文字完整、不缩字，故意越框的负例必须被拒绝。
- control implementation 升为 v14 并绑定新安全/排版/渲染代码；离线参考评测仍 `admission.eligible=false`，不能推导正式准入或重写旧批准。

永久回归覆盖 URI port 注入/括号 host/编码大小写、source map 数值上限、连接函数保留、loopback WebSocket 异常握手与选择器线性扫描行为。保留真实网络边界与构建回归；patch 版本不等于零兼容风险。

## 恢复方式

本轮同步清单逐项保存修改前后 SHA 与原始字节。需要撤回时只恢复本轮涉及文件，先确认当前文件仍等于本轮 after SHA，再恢复 before；不触碰历史 dirty 或使用全仓库 reset。依赖恢复须回到对应 package/workspace/lock 三件套后执行 frozen install。旧媒体始终保留，不拿新版代码覆盖它们。
