# AI Concept Studio 项目上下文

## 1. 用户目标

用户要长期经营一个抖音 AI 知识分享账号，并长期开发、维护一套由 Codex 协助建设的视频生产 Agent 系统。计划每周发布 2～3 条视频。

用户编程基础较少，但理解 Agent 的底层原理。因此系统应提供非技术化界面、明确状态、人工审批和可恢复流程，不能要求用户日常手写代码或依赖一次性提示词。

这不是“帮用户制作某一条视频”的项目，而是持续生产和迭代的内容系统。

## 2. 内容产品定位

- 平台：抖音；
- 默认形式：8～12 分钟、9:16 竖屏长视频；
- 频率目标：每周 2～3 条；
- 栏目任务：每期讲透一个近期热门或新出现的 AI 技术概念；
- 核心观众：AI 产品经理、AI 创业者、解决方案与战略人员等“技术邻近型”人群；
- 观众基础：听过 LLM、Token、API、RAG、Agent 等术语，能看懂简单架构图，但不具备程序员级工程细节；
- 价值承诺：让观众能准确解释概念、识别营销包装、理解机制与边界，并参与产品方案讨论。

内容应回答定义、出现背景、旧问题、工作机制、相似概念对比、能力边界、工程代价、产品影响和采用判断。

“Loop”曾经只是用户举例说明“新概念出现后要及时讲清楚”，不是项目当前唯一选题，也不应把系统误解成专门制作 Loop 视频。

## 3. 选题原则

- 选题聚焦“近期 AI 热点概念解析”，不是热点事件复述；
- 产品发布、融资、人物发言或大会新闻只能作为发现概念的入口，不能直接成为主选题；
- 要参考多个主流热门 AI 博主近期在讲什么，优先选择已经形成独立创作者共振的概念；
- 很少有人讨论、没有市场信号的概念暂不发布；
- 竞品内容只证明市场热度，不能作为技术事实来源；
- 技术事实必须回到官方文档、官方博客、论文、标准、模型卡或官方仓库；
- 缺失的播放量、评论数或互动指标保持缺失，禁止猜测和伪造；
- 已制作概念、事件主导项和观察池候选不得绕过门槛进入正式研究。

## 4. 表达与视觉决策

视频需要有活力和吸引力，但活力来自叙事推进、观点冲突、真实任务和画面变化，不依赖夸张口吻或“震惊、颠覆一切”等表达。

用户否决了 AI 感过重的视觉方向，最终确认：

**视觉方向 B — 真实产品纪录片。**

当前视觉关键词：明亮、中性、真实、清楚、克制、有证据。

画面优先级：

1. 真实产品录屏与真实操作；
2. 可核验的界面、文档、日志、Diff 和测试结果；
3. 真实人物肩后、手部和工作现场素材；
4. 用于解释关系的扁平架构图、流程图和对比表；
5. 极少量明确标注的示意素材。

默认禁用深色科技背景、霓虹、HUD、粒子、AI 大脑、机器人头、泛蓝紫渐变、伪造产品 UI 和 AI 生成人物冒充实拍。AI 氛围素材默认关闭。

详细标准位于 `docs/05-visual-system.md`。

## 5. 系统架构

系统采用“可追溯状态 + Agent 模块 + 人工闸门”的架构。

```text
公开创作者页面
→ 创作者信号采集 Agent
→ 热点概念发现 Agent
→ 人工选择选题
→ Research Agent / 一手资料证据包
→ 人工事实审批
→ Script Agent
→ 人工脚本审批
→ Storyboard Agent
→ 人工视觉审批
→ Asset Agent
→ Voice Agent
→ 人工声音审批
→ Render Agent
→ QA Agent
→ 人工终审与手动发布
```

每一期的唯一状态源是 `studio/data/episodes/<期数>/episode.json`。图片、音频、Markdown 和视频作为独立文件保存，状态源只记录相对路径与元数据。

热点雷达、采集数据和研究证据有独立数据域，避免把“市场热度”混入“事实证据”。

## 6. 人工闸门

以下节点必须由人确认：

- 选题；
- 关键事实；
- 脚本；
- 视觉；
- 声音；
- 最终成片。

系统不自动发布抖音内容，也不允许 Agent 自行越过闸门。

## 11. 安全与事实规则

- 不把 `.env`、API Key、Cookie、账号令牌或凭据提交到 Git；
- `studio/config/cloud-backup.local.json` 只保存当前电脑的 OneDrive 路径，已被 Git 忽略；
- `node_modules`、缓存、日志和生成视频不进入普通 Git 历史；
- 视频和大素材由 OneDrive 管理，代码与小型 JSON 状态由 GitHub 管理；
- 真实产品 UI、测试和结果不得由生成式 UI 冒充；
- 研究证据未达到来源、主张、交叉核验和关键类别门槛时，不得批准事实；
- 发布保持手动，账号操作和高风险动作由人确认。
