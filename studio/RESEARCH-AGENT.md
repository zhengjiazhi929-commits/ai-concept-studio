# Research Agent v0.1

Research Agent 把人工选中的热点概念转化为可审批的一手证据包。它不把热门博主的视频当作技术事实，也不会因为网页能打开就自动声称事实已经得到证明。

## 输入与输出

输入来自 `data/trends/selection.json`，包含概念、标题、产品决策问题、近期创作者信号和预先配置的一手来源计划。人工在热点雷达中选题后，系统会同时创建对应的一期草稿。

运行 Research Agent 后会生成：

- `data/research/episodes/<一期>/latest.json`：当前研究证据包；
- `data/research/runs/`：每次研究运行的可追溯快照；
- `data/research/assist-task.json`：需要 Codex 或人工完成的语义核验任务；
- `data/research/inbox/`：经过校验后导入的证据批次。

## 工作流程

```text
热点正式候选
→ 人工选题并创建一期草稿
→ 读取概念词典中的一手来源计划
→ 检查 HTTPS、网页状态、内容类型、体积和内容哈希
→ 生成 8 类事实问题与 Codex 辅助任务
→ 导入来源、主张、定位和适用边界
→ 自动检查证据门槛
→ 人工批准关键事实
→ 进入脚本 Agent
```

网页可读取只代表资料可访问。只有导入了来源中的核验结论、定位信息和适用边界，来源才会记为“证据已核验”。

## 事实审批硬门槛

默认配置位于 `config/research.json`。当前要求：

- 至少 3 份已核验一手来源；
- 至少 2 份官方、论文、标准、官方仓库或基准来源；
- 至少 6 条获得来源支持的主张；
- 至少 2 条主张经过两个独立来源交叉核验；
- 定义、机制、边界与产品影响四类关键问题必须覆盖；
- 任何关键主张如果仍为 partial、disputed 或 unsupported，不能进入事实审批。

## 允许的来源

- 官方文档与规范；
- 官方产品或工程博客；
- 官方仓库；
- 论文；
- 标准；
- 基准官网或原始发布。

创作者视频、二手转载、搜索摘要和模型自行生成的答案不能登记为事实来源。它们可以帮助发现问题或判断热度，但必须回到一手资料核验。

## 运行方式

最简单的方式是在控制台中选择正式候选，然后点击“运行研究 Agent”。命令行等价操作：

```text
pnpm research
pnpm import:research -- <data/research/inbox 中的批次文件名>
```

Research Agent 没有配置通用模型 API，也不会隐藏这一点。当前版本通过结构化任务让 Codex 或人工完成语义证据提取；后续接入模型供应商时，仍必须保留相同的来源、边界和人工审批约束。
