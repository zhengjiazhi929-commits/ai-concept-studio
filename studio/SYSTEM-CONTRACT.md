# AI Concept Studio 系统合同 v0.1

## 目标

把近期热门 AI 技术概念转化为面向 AI 产品经理的 8～12 分钟竖屏知识视频，并保留事实来源、人工审批、可复现素材和质量报告。

## 系统边界

- Agent 可以搜集、整理、起草、编排、渲染和检查；
- 人必须批准选题、关键事实、脚本、声音和最终发布；
- 第一版只在本机运行，不自动发布、不保存第三方密钥；
- 所有一期内容都写入独立目录，失败后可以从最近状态继续；
- 竞品内容只作为热度信号，一手来源才可以支撑技术主张；
- 视频中的真实产品画面、测试和结果不得由生成式 UI 冒充。

## 一期数据真源

每一期只有一个 `episode.json`，记录：

- 主题、受众与核心命题；
- Agent 流水线状态；
- 人工审批状态；
- 来源文档与内容哈希；
- 场景、字幕、素材和时间轴；
- 渲染输出、QA 结果和已知限制。

Markdown、图片、音频和视频仍是独立文件，`episode.json` 只保存相对路径和元数据。

## 系统级热点雷达

热点概念发现发生在创建具体一期内容之前，因此它有独立的数据域：

- `data/trends/signals.json` 保存可追溯的创作者市场信号；
- `data/trends/latest.json` 保存最近一次聚类、门槛和排名结果；
- `data/trends/selection.json` 保存人工选中的 Research Agent 输入；
- 竞品信号不能进入事实证据包，除非其内容本身指向并可核对一手来源；
- 观察池、事件主导项和已经制作的概念不能绕过后端门槛进入研究阶段。

## 创作者信号采集

- 采集器只读取无需登录的公开页面，不保存 Cookie、账号令牌或私有接口参数；
- 平台无法程序直读时必须生成 Codex 辅助任务，不能把网页外壳记为成功；
- 采集失败、待复核和过期观察不能覆盖已有可用信号，也不能参与热点排名；
- 每条入库信号必须保留创作者、来源链接、发布时间、观察时间和采集批次；
- 公开互动数据可以记录，缺失字段必须保持缺失。

## Agent 接口

```text
agent.run(episode, context)
→ status, artifacts, findings, nextAction, requiresApproval
```

Agent 不能直接跨越人工闸门。失败必须留下可读日志，不覆盖上一版可用产物。

## 完成标准

系统第一阶段只有同时满足以下条件才算打通：

1. 黄金样例可以导入为结构化一期数据；
2. 控制台能读取状态、运行模块并显示日志；
3. 真实素材能生成一个竖屏 MP4；
4. 自动 QA 能核对尺寸、时长、编码和必需文件；
5. 重新启动后仍能读取原状态和输出；
6. 未配置模型或声音供应商时，系统明确显示等待配置，不伪装完成。
7. 热点候选能说明来自哪些独立创作者、哪些维度缺失，以及为什么通过或未通过门槛。
8. 采集批次能区分程序直读、Codex 辅助、待复核、过期与失败状态，并能从历史批次恢复。
