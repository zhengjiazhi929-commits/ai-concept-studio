# Agentic Coding 本地演示项目

这是黄金样例视频使用的本地 SaaS 演示环境，所有客户、公司、电话和邮箱均为虚构数据。

它用于真实记录以下过程：

1. Agent 读取任务和项目；
2. 运行验收测试并看到失败；
3. 修改权限、脱敏和异步导出逻辑；
4. 重新运行测试；
5. 在浏览器中验证结果；
6. 查看 Diff 和交付证据。

## 重要说明

- 当前初始版本**故意保留不合格的批量导出实现**，用于演示 Agent 如何根据真实失败反馈完成任务；
- 不得把本项目用于生产环境；
- 不含真实账号、密钥、客户数据或第三方服务；
- 视频中必须标注“本地演示环境 / 虚构数据”。

## 运行

使用项目配置的 Node.js：

```text
npm test
npm start
```

默认访问：`http://127.0.0.1:4173`

正式录制前，以 `TASK.md` 为任务合同，以 `tests/export.test.mjs` 为可执行验收条件。
