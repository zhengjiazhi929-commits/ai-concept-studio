# 任务合同：完成客户批量导出

## Goal

完善客户管理后台的批量导出功能，使其能够在不阻塞页面的情况下生成可下载的 CSV。

## Context

- 当前项目已有客户列表和一个不合格的同步导出接口；
- 所有数据均为本地生成的虚构数据；
- 项目只使用 Node.js 内置能力，不添加外部依赖；
- 验收测试位于 `tests/export.test.mjs`。

## Constraints

1. 只有 `admin` 角色能够创建导出任务；
2. `viewer` 等非管理员角色必须收到 `403`；
3. CSV 中邮箱和手机号必须脱敏；
4. 导出通过后台任务完成，创建任务时返回 `202`，不能直接在请求中生成并下载大文件；
5. 不读取环境变量、外部网络、真实数据或敏感信息；
6. 不执行部署、数据库迁移或删除资源；
7. 不修改与本任务无关的文件。

## Acceptance

- `node --test tests/*.test.mjs` 全部通过；
- 管理员可以创建导出任务、查询状态并下载 CSV；
- 普通用户无法创建导出；
- 下载文件不包含完整手机号或完整邮箱；
- 浏览器中的导出状态能从“准备中”更新为“可以下载”；
- 最终交付包含改动摘要、测试结果和已知限制。

## Stop conditions

- 需求含糊且会影响权限或数据处理时，先提出问题；
- 需要外部依赖、联网或高风险操作时，停止并请求批准；
- 连续尝试后测试仍失败时，保留日志并交还人工。
